# AI 运维控制台（aiomss）

> 一个**纯本地运行**的 Web 运维控制台：在你自己的电脑上，用浏览器连接并管理多台 Linux 服务器，
> 并让大模型（LLM）充当运维助手——自动执行诊断命令、分析日志、巡检系统、讲解命令，
> 危险操作先弹窗确认再执行，全过程逐条可审计。

```
浏览器 (xterm.js 终端 + AI 面板)
        │  HTTP / SSE
        ▼
本机 FastAPI 后端  ──SSH(paramiko)──▶  多台 Linux 主机
        │
        └──HTTPS──▶  大模型 API（OpenAI 兼容：DeepSeek / 通义 / 任意兼容端点）
```

---

## 一、它是做什么的

日常运维里，我们常在多个服务器之间反复切换、敲命令、翻日志，还得记住各种排障步骤。
这个工具把三件事放进同一个页面：

1. **多主机 SSH 终端** —— 在浏览器里获得真正的交互式 shell（支持 Tab 补全、`vim`、`top`、颜色），
   一台台服务器连上即用，无需在本地装 XShell/FinalShell。
2. **AI 运维助手** —— 右侧抽屉里用自然语言提问，例如「帮我看看这台机器磁盘为什么满了」「CPU 高排查一下」，
   AI 会调用大模型自主执行只读诊断命令，把每一步的命令、风险、输出、退出码、耗时完整列出；
   涉及写操作（改配置、删文件、重启服务）时**先弹确认框**，由你决定放不放行。
3. **本地命令审计** —— 每次「连接 → 断开」生成一个 `用户名_时间.txt`，把终端屏幕上出现过的内容
   **1:1 全量转录**落盘（登录横幅、命令回显、输出、报错、提示符都在），原始字节流另存 `raw/`，
   随时可以问 AI「审计：谁在什么时候执行了什么」，AI 直接读本地审计文档作答。

此外还有：文件管理（SFTP 上传/下载，可取消）、会话保活、多套 API 接入随时切换、
多套配色主题、自动图形验证码登录、危险命令审批等。

**它不做什么**：不主动部署到服务器、不把你的数据上传到任何第三方、不暴露到局域网。
服务默认只监听 `127.0.0.1:8848`，所有配置与审计文件都留在你本机。

## 二、适合谁用

- 需要同时管理几台服务器、又不想堆一堆终端窗口的运维 / 开发；
- 想让 AI 帮忙排查问题，但不放心把生产环境完全交给自动化的工程师；
- 需要一份「谁、什么时候、在这台机器上做了什么」的可追溯本地审计记录。
  > 面向个人/小团队本地使用，**不建议直接暴露到公网**。

## 三、快速开始

环境：Windows（推荐）或 Linux / macOS，Python 3.9+。

**Windows**：双击 `scripts/start.bat`
**Linux / macOS**：`bash scripts/start.sh`

首次启动脚本会自动检测依赖、创建独立 `venv` 并联网安装所需包，约几十秒；之后秒开。
启动后浏览器自动打开 <http://127.0.0.1:8848>，进入登录页（账号 `admin`，密码由本机配置决定，见下文）。
关闭那个黑色控制台窗口即停止服务。

手动启动：

```bash
python -m venv venv
venv/Scripts/python.exe -m pip install -r requirements.txt   # Windows
# source venv/bin/activate && pip install -r requirements.txt  # Linux/macOS
python -m backend.app
```

依赖：`fastapi`、`uvicorn`、`paramiko`、`requests`、`cryptography`、`pillow`。
前端 `xterm.js` 已随仓库提供，**无需 npm、不连 CDN，完全离线可用**。

## 四、配置说明（重要）

仓库里**不含任何真实 API Key、登录口令或服务器密码**。

- `config/config.example.json` 是配置模板；首次运行会生成 `config/config.json`。
- API Key **只保存在后端本机配置**，前端只显示脱敏值，不会下发完整密钥。
- 在页面顶栏「⚙ API修改」里可新增多套 OpenAI 兼容接入（DeepSeek、通义、自建端点等），
  填入 **API 地址 + Key + 模型名** 后即可测试与切换；模型名不要填到「名称」框。
- SSH 主机密码用 Fernet 加密落盘；登录密码只存 PBKDF2 散列；图片验证码一次性有效。
- 修改登录密码：`python scripts/set_password.py`。

> ⚠️ 若你 fork 后打算给他人使用或部署到非本机环境，请务必使用自己的密钥，
> 并**改掉默认登录口令**（见 `backend/auth.py` 的 `DEFAULT_PASSWORD`）。
> 默认口令与示例 IP 仅用于本地演示与自动化测试。

## 五、功能一览

| 能力 | 说明 |
| --- | --- |
| 交互式 SSH 终端 | 浏览器内真实 shell，Tab 补全 / vim / top / 彩色输出 |
| AI 自主诊断 | 自然语言提问，AI 执行只读命令并给出完整过程报告 |
| 危险操作审批 | 写类命令先弹确认，用户放行才执行 |
| AI 结论呈现 | 完整报告 + 分段小节 + 逐行编号建议，阶段进度置顶 |
| 文件管理 | SFTP 目录浏览、上传、下载，传输中可取消 |
| 会话保活 | 可配置定时字符与间隔，防止长连接被断开 |
| 多 API 接入 | 多套模型并存，页面随时切换；地址/模型可在线拉取 |
| 多套配色 | 6 种主题，终端与界面同步切换 |
| 本地审计 | 终端内容 1:1 落盘 + 原始字节流，跨会话检索、导出、交给 AI 分析 |
| 登录安全 | 图片验证码、失败锁定、HttpOnly Cookie、8 小时会话 |

## 六、目录结构

```
aiomss/
├── backend/            FastAPI 服务、SSH/SFTP、AI 客户端、审计与终端转录
├── frontend/           页面、样式、脚本、内置 xterm.js
├── config/             config.example.json（模板）；config.json 为本地真实配置（不入库）
├── scripts/            start.bat / start.sh、图标与快捷方式生成、各类测试脚本
├── assets/             图标与界面预览图
├── docs/               详细使用文档 README.md、测试报告 TEST_REPORT.md
├── audit/              运行时生成的会话审计文件（不入库）
├── logs/               运行日志（不入库）
├── venv/               本地虚拟环境（不入库）
└── requirements.txt    Python 依赖
```

完整功能说明见 [`docs/README.md`](docs/README.md)；测试与验证见 [`docs/TEST_REPORT.md`](docs/TEST_REPORT.md)。

## 七、安全与隐私

- 服务只绑定 `127.0.0.1`，不对外网开放；
- 所有服务器地址、账号、密钥、审计记录都只存本机，仓库与前端均不包含真实凭据；
- AI 执行写操作前必须人工确认；审计对命令中的口令、Token、Bearer 等自动脱敏；
- 本项目适合本地运维提效，**请勿在未经加固（鉴权 / HTTPS / 网络隔离）的情况下暴露到公网**。
